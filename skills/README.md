# Skills

Skills are task-oriented; books live in `packs/` and do not become one Skill per book or catalog item.

- `design-review`: review non-trivial changes;
- `complexity-audit`: audit a diff or code area;
- `safe-refactoring`: perform behavior-preserving structural change;
- `design-twice`: compare alternatives and apply YAGNI;
- `architecture-decision`: record durable architecture tradeoffs;
- `assumption-audit`: inspect load-bearing premises and competing explanations for engineering or daily decisions.

Reasoning Packs are progressively disclosed: only `assumption-audit` or an explicit Hook `reasoning_mode` loads their compact runtime capsule.
